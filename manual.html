1. Introdução

Bem-vindo ao sistema de Automação de Contratos! Este sistema foi desenvolvido para facilitar o processo de geração de contratos de trabalho, extraindo automaticamente informações das fichas cadastrais dos empregados em formato PDF.

💡 O que este sistema faz?
O sistema lê fichas de empregados em PDF, extrai automaticamente os dados necessários e preenche modelos de contratos pré-configurados, economizando tempo e reduzindo erros manuais.

2. Requisitos do Sistema

✓ Antes de começar, verifique:

  • O sistema está instalado e funcionando corretamente
  • Você tem acesso às fichas de empregados em formato PDF
  • Os modelos de contratos estão na pasta Modelos
  • Você tem permissão para salvar arquivos na pasta de destino escolhida

3. Primeiros Passos

1 Iniciar o Sistema

Execute o programa main.py ou o executável fornecido. A interface do sistema será aberta automaticamente.

2 Conhecer a Interface

A tela está dividida em duas áreas principais:

  • Painel Esquerdo (Sidebar): Contém os botões e controles principais
  • Painel Direito: Exibe os dados do empregado para edição

4. Como Usar o Sistema

4.1. Selecionar Fichas de Empregados

1 Clique no botão "📂 Selecionar PDFs"

Localizado na seção "1. FICHAS DE EMPREGADO" do painel esquerdo.

2 Escolha os arquivos PDF

Na janela que abrir, navegue até a pasta onde estão as fichas dos empregados. Você pode selecionar múltiplos arquivos PDF de uma vez:

  • Para selecionar um arquivo: Clique nele
  • Para selecionar múltiplos arquivos: Mantenha a tecla Ctrl pressionada e clique em cada arquivo desejado
  • Para selecionar um intervalo: Clique no primeiro arquivo, mantenha Shift pressionado e clique no último

3 Confirme a seleção

Clique em "Abrir" ou "Selecionar" para confirmar. O sistema começará a processar os arquivos automaticamente.

⏳ Processamento Automático
Após selecionar os PDFs, o sistema extrairá automaticamente os dados de cada ficha. Você verá uma mensagem de status indicando o progresso. Aguarde até que todos os arquivos sejam processados.
✅ Sucesso!
Quando o processamento terminar, você verá uma lista dos arquivos processados com um ícone ✅ ao lado de cada um. Se algum arquivo tiver problemas, aparecerá um ícone ❌.

4.2. Visualizar Dados Extraídos

1 Navegar entre empregados

Após o processamento, os dados do primeiro empregado aparecerão automaticamente no painel direito. Use os botões "◀ Anterior" e "Próximo ▶" para navegar entre os empregados processados.

2 Verificar informações

Revise todos os campos extraídos para garantir que estão corretos. Os campos disponíveis incluem:

  • Dados da Empresa (Nome, CNPJ, Endereço)
  • Dados do Empregado (Nome, CPF, RG, CTPS, etc.)
  • Informações de Trabalho (Função, Salário, Data de Admissão, etc.)

5. Editar Dados Extraídos

1 Localizar o campo

No painel direito, encontre o campo que deseja editar. Todos os campos são editáveis diretamente na tela.

2 Fazer a correção

Clique no campo desejado e digite ou corrija a informação. As alterações são salvas automaticamente quando você navegar para outro empregado ou gerar os contratos.

⚠️ Atenção!
Sempre revise os dados antes de gerar os contratos. Erros nos dados podem resultar em contratos incorretos. Os dados são salvos automaticamente quando você navega entre empregados ou ao gerar os contratos.

3 Navegar entre empregados

Use os botões de navegação para revisar e editar os dados de todos os empregados antes de gerar os contratos.

6. Gerar Contratos

6.1. Selecionar Modelos de Contrato

1 Verificar modelos disponíveis

Na seção "2. MODELOS DE CONTRATO" do painel esquerdo, você verá uma lista de todos os modelos de contrato disponíveis na pasta Modelos.

2 Marcar/Desmarcar modelos

Use as caixas de seleção (checkboxes) ao lado de cada modelo para escolher quais contratos deseja gerar:

  • Marcado (✓): O contrato será gerado
  • Desmarcado: O contrato não será gerado

Por padrão, todos os modelos estão marcados.

6.2. Gerar os Contratos

1 Escolher pasta de destino

Clique no botão "⚡ Gerar Contratos" na seção "3. GERAR CONTRATOS". Uma janela será aberta para você escolher onde salvar os contratos gerados.

2 Selecionar a pasta

Navegue até a pasta onde deseja salvar os contratos e clique em "Selecionar Pasta" ou "OK".

3 Aguardar processamento

O botão mudará para "⏳ Gerando..." e você verá uma mensagem de status. Aguarde até que todos os contratos sejam gerados. O tempo depende da quantidade de empregados e modelos selecionados.

✅ Contratos Gerados!
Quando o processo terminar, você verá uma mensagem informando quantos contratos foram gerados com sucesso. A pasta de destino será aberta automaticamente para você visualizar os arquivos.

6.3. Estrutura dos Arquivos Gerados

Organização dos arquivos

Os contratos são organizados da seguinte forma:

  • Uma pasta é criada para cada empregado (usando o nome do empregado)
  • Dentro de cada pasta, os contratos são salvos com o nome do modelo seguido do nome do empregado
  • Exemplo: Contrato de Trabalho - João Silva.docx

7. Mapeamento de Placeholders

Os placeholders são marcadores especiais usados nos modelos de contrato. Durante a geração, cada placeholder é substituído automaticamente pelo valor extraído da ficha do empregado. Abaixo está a lista completa de todos os placeholders disponíveis no sistema.

💡 O que é um placeholder?
É um texto entre chaves duplas, como {{NOME}}, que serve de "espaço reservado" dentro do modelo de contrato. Quando o sistema gera o contrato, ele troca esse texto pelo dado real do empregado (ex: "João da Silva").
Placeholder Descrição Exemplo de Valor
Dados da Empresa
{{EMPRESA}} Nome / Razão social da empresa Empresa ABC Ltda
{{EMPRESA_CNPJ}} CNPJ da empresa 12.345.678/0001-90
{{EMPRESA_ENDERECO}} Endereço completo da empresa Rua das Flores, 100, Centro, Campinas, SP
{{CIDADE}} Cidade (extraída do endereço da empresa) Campinas
Dados Pessoais do Empregado
{{NOME}} Nome completo do empregado João da Silva
{{CPF}} CPF do empregado 123.456.789-00
{{RG}} RG (Cédula de Identidade) 12.345.678
{{CTPS}} Número da CTPS 12345
{{CTPS_SERIE}} Série da CTPS 0001
{{DATA_NASCIMENTO}} Data de nascimento 15/03/1990
{{LOCAL_NASCIMENTO}} Local de nascimento Campinas
{{PAIS_NACIONALIDADE}} País / Nacionalidade Brasileiro(a)
{{ESTADO_CIVIL}} Estado civil Solteiro
{{ENDERECO}} Endereço residencial do empregado Rua dos Lírios, 50, Jardim, Campinas, SP
Informações de Trabalho
{{FUNCAO}} Cargo / Função do empregado Auxiliar Administrativo
{{SALARIO}} Salário (valor numérico) 2.500,00
{{SALARIO_EXTENSO}} Salário por extenso dois mil e quinhentos reais

Contrato de Experiência

{{QUANTIDADE_DIAS}} Quantidade de dias do contrato 45

⚠️ Importante: Os nomes dos placeholders são sensíveis a maiúsculas/minúsculas. Use exatamente como mostrado na tabela acima (tudo em MAIÚSCULAS). Exemplo: {{NOME}} funciona, mas {{nome}} ou {{Nome}} não funcionam.

8. Como Usar Placeholders nos Modelos

Esta seção ensina como criar ou editar modelos de contrato para que o sistema preencha automaticamente os dados dos empregados.

8.1. Regras Básicas

! Regras para os placeholders

  • Sempre use chaves duplas: {{NOME_DO_CAMPO}}
  • O nome do campo deve estar em MAIÚSCULAS e ser exatamente igual ao da tabela acima
  • Não coloque espaços dentro das chaves: {{ NOME }} pode não funcionar
  • O placeholder pode estar em qualquer parte do texto: parágrafos, tabelas, cabeçalhos ou rodapés
  • Os valores preenchidos automaticamente aparecerão em negrito no contrato final

8.2. Passo a Passo: Editar um Modelo Existente

1 Abrir o modelo

Navegue até a pasta Modelos do sistema e abra o arquivo .docx desejado no Microsoft Word.

2 Localizar onde inserir o placeholder

Encontre no texto do contrato o local onde a informação deve ser preenchida automaticamente. Por exemplo, onde aparece o nome do empregado.

3 Digitar o placeholder

Apague o texto de exemplo e digite o placeholder correspondente com as chaves duplas. Por exemplo, onde estava "Fulano de Tal", digite {{NOME}}.

⚠️ Dica crucial: Ao digitar o placeholder no Word, digite tudo de uma vez, sem pausas longas. Se o Word dividir o texto em partes diferentes internamente (o que pode acontecer ao copiar/colar ou editar letra por letra), o placeholder pode não ser reconhecido. Em caso de dúvida, apague o texto e redigite {{NOME}} de forma contínua.

4 Salvar o modelo

Salve o arquivo normalmente (Ctrl + S). Certifique-se de que continua salvo como .docx na pasta Modelos.

8.3. Passo a Passo: Criar um Modelo Novo

1 Criar o documento

Abra o Microsoft Word e crie um novo documento ou copie um modelo existente.

2 Escrever o texto do contrato

Escreva o contrato normalmente. Nos locais onde deve entrar uma informação variável (nome, CPF, salário, etc.), insira o placeholder correspondente.

3 Salvar na pasta correta

Salve o arquivo como .docx dentro da pasta Modelos do sistema. O novo modelo aparecerá automaticamente na lista de modelos disponíveis na próxima vez que o sistema for aberto.

8.4. Exemplo Prático

Veja como um trecho de modelo fica antes e depois da geração:

No modelo (.docx) você escreve:

A empresa {{EMPRESA}}, inscrita no CNPJ sob nº {{EMPRESA_CNPJ}}, com sede em {{EMPRESA_ENDERECO}}, neste ato denominada EMPREGADORA, e o(a) Sr(a). {{NOME}}, portador(a) do CPF nº {{CPF}}, RG nº {{RG}}, CTPS nº {{CTPS}} série {{CTPS_SERIE}}, residente em {{ENDERECO}}, neste ato denominado(a) EMPREGADO(A), celebram o presente contrato de experiência pelo prazo de {{PERIODO_EXPERIENCIA}} dias, com início em {{DATA_ADMISSAO}} e término em {{DATA_FINAL}}.

O sistema gera o contrato preenchido assim:

A empresa Empresa ABC Ltda, inscrita no CNPJ sob nº 12.345.678/0001-90, com sede em Rua das Flores, 100, Centro, Campinas, SP, neste ato denominada EMPREGADORA, e o(a) Sr(a). João da Silva, portador(a) do CPF nº 123.456.789-00, RG nº 12.345.678, CTPS nº 12345 série 0001, residente em Rua dos Lírios, 50, Jardim, Campinas, SP, neste ato denominado(a) EMPREGADO(A), celebram o presente contrato de experiência pelo prazo de 45 dias, com início em 01/02/2026 e término em 17/03/2026.

8.5. Exemplo: Cláusula de Prorrogação

Use os placeholders de prorrogação para cláusulas sobre extensão do contrato:

No modelo:

O presente contrato poderá ser prorrogado por mais {{DIAS_PRORROGACAO}} dias, encerrando-se em {{FIM_PRORROGACAO}}, conforme legislação vigente.

Resultado gerado:

O presente contrato poderá ser prorrogado por mais 45 dias, encerrando-se em 01/05/2026, conforme legislação vigente.

8.6. Exemplo: Cláusula de Remuneração

No modelo:

O EMPREGADO receberá o salário mensal de R$ {{SALARIO}} ({{SALARIO_EXTENSO}}), a ser pago até o 5º dia útil do mês subsequente.

Resultado gerado:

O EMPREGADO receberá o salário mensal de R$ 2.500,00 (dois mil e quinhentos reais), a ser pago até o 5º dia útil do mês subsequente.
✅ Pronto!
Agora você sabe como usar os placeholders nos modelos de contrato. Lembre-se: qualquer placeholder da tabela da seção 7 pode ser usado em qualquer parte do documento Word.

9. Resolução de Problemas

7.1. Arquivo PDF não foi processado

Problema: Um arquivo aparece com ícone ❌ na lista
Solução:
  • Verifique se o arquivo PDF não está corrompido
  • Certifique-se de que o PDF contém texto (não é apenas uma imagem escaneada)
  • Tente abrir o PDF em outro programa para confirmar que está acessível
  • Se o problema persistir, entre em contato com o suporte técnico

7.2. Dados extraídos incorretamente

Solução: Você pode editar manualmente qualquer campo na tela antes de gerar os contratos. Basta clicar no campo e corrigir a informação.

7.3. Contratos não foram gerados

Verifique:
  • Se pelo menos um modelo de contrato está marcado
  • Se você tem permissão para escrever na pasta de destino escolhida
  • Se há espaço suficiente no disco
  • Se os modelos de contrato estão na pasta Modelos

7.4. Sistema está lento

Dicas:
  • Processar muitos arquivos ao mesmo tempo pode demorar. Aguarde pacientemente.
  • Evite processar mais de 50 arquivos por vez
  • Feche outros programas pesados enquanto usa o sistema

10. Dúvidas Frequentes

Posso processar quantos arquivos por vez?

Sim, você pode selecionar múltiplos arquivos PDF de uma vez. Recomendamos processar até 50 arquivos por vez para melhor performance.

Os dados são salvos automaticamente?

Sim, as alterações nos dados são salvas automaticamente quando você navega para outro empregado ou ao gerar os contratos.

Posso editar os dados depois de gerar os contratos?

Sim, você pode editar os dados a qualquer momento antes de gerar os contratos. Após gerar, você precisaria processar novamente os PDFs para alterar os dados.

Onde ficam salvos os contratos gerados?

Os contratos são salvos na pasta que você escolher quando clicar em "Gerar Contratos". A pasta será aberta automaticamente após a geração.

Posso gerar apenas alguns modelos de contrato?

Sim, use as caixas de seleção ao lado de cada modelo para marcar apenas os que deseja gerar.

O que fazer se um campo importante não foi extraído?

Você pode preencher manualmente qualquer campo na tela antes de gerar os contratos. Todos os campos são editáveis.
